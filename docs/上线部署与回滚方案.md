# 上线部署与回滚方案

本文覆盖在职工资迁移主线的 Spring Boot + MySQL 部署。退休工资按独立项目处理。

## 1. 上线前门禁

执行完整门禁：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\verify-launch-readiness.ps1
```

如服务正在运行导致 jar 被锁，可先执行一次手工打包和启动，再运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\verify-launch-readiness.ps1 -SkipPackage
```

归档：

```text
backend\target\launch-readiness-report.txt
backend\target\history-write-rehearsal-report.txt
backend\target\real-history-write-precheck.txt
backend\target\production-permissions\permission-snapshot.txt
backend\target\data-governance-ledger\data-governance-ledger.txt
```

## 2. 部署步骤

1. 停止 18080 上旧服务。
2. 设置数据库密码：

```powershell
$env:DB_PASSWORD='<your-local-password>'
```

3. 打包：

```powershell
cd backend
mvn -DskipTests package
```

4. 启动：

```powershell
Start-Process -FilePath "java" -ArgumentList @("-jar", "target\rsgzgl-backend-0.1.0-SNAPSHOT.jar") -WorkingDirectory "D:\rsgzgl2006nid\backend" -WindowStyle Hidden
```

5. 检查：

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:18080/
```

## 3. 回滚策略

优先级从低风险到高风险：

1. 未执行历史写入：撤销/取消业务 case 或保留为阻断台账，不改 `hisbase`。
2. 已执行历史写入：使用系统撤销写入，按计划恢复 `sid` 链。
3. 批次异常：根据 `HWB-WRITE-*` 和 `HWB-ROLLBACK-*` 批次审计导出逐条核查。
4. 系统性异常：停止服务，恢复上线前数据库备份。

## 4. 必须归档

- 当前 git commit；
- jar 文件时间；
- 数据库备份文件和校验值；
- 上线门禁报告；
- 真实小批预检清单；
- 权限快照；
- 数据治理台账；
- 写入计划、写入流水、撤销流水。

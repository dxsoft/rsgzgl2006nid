# 在职工资阶段性交付说明

本文记录当前 Spring Boot + MySQL 重构中，在职工资试算阶段的交付范围、验证状态和后续工作。

## 1. 交付范围

当前交付对象为在职人员工资试算与历史工资结果复核，不包含退休工资和年终一次性奖金。

核心接口：

- `POST /api/salary/rule-trial/normal-grade`：单人规则试算。
- `POST /api/salary/rule-trial/normal-grade-batch`：批量规则试算。
- `GET /api/salary/rule-trial/normal-grade-batch.csv`：批量试算 CSV 导出。

辅助页面：

- Spring Boot 静态页面：`http://127.0.0.1:18080/`

## 3. 关键规则口径

- 目标历史行选择支持 `changeType/jslb` 精确匹配；传入变动类型时，不再回退到同月其他记录。
- 正常晋档按 `zwbm2` 前缀判断，不按 `dwsx` 判断。
- 公务员/参公累计 5 年考核称职及以上晋升级别；累计 2 年晋档。
- 事业人员累计 1 年考核合格及以上晋升薪级。
- 机关工人按岗位档次或技术等级变化处理。
- `21/22` 前缀等级工资查 `bz06_djgz`，其他公务员/参公级别工资查 `bz06_jbgz`。
- `03` 法检等级工资查 `bz06_zwgz_fj`，结果写入 `ZWGZSE2`。
- 见习工资按见习时学历 `dxl.xlbm` 查表，不直接依赖历史行 `xlbm`。
- 学历类别为 `其他/其它` 不参与工资。
- 津补贴中已纳入 `jbtbz` 的字段按岗位和标准年度取标准，手工/特殊项目保留或归入例外。
- `2006套改` 金额项目按目标套改行重建，`TG2006_TGB/XJ/GR` 用于非金额校验和差异归类。

## 8. 交付建议

业务验收建议按以下顺序执行：

1. 使用 `docs/在职工资试算验收清单.md` 做接口和规则验收。
2. 抽查代表样本：正常晋档、职务变化、新进工资、学历变化、警衔/职级、法检、2006 套改。
3. 每次规则调整后先跑 `mvn test`，再跑 `verify-salary-samples.ps1 -FailOnUnexpected`。
4. 新增已知例外必须写入 `known-sample-issues.tsv`，并说明原因。
5. 在职工资验收完成后，再进入退休独立项目。

# 在职工资试算验收清单

本文用于前端联调、业务验收和规则回归复测。退休工资暂不纳入本清单，后续按独立项目处理。

## 1. 接口范围

### 单人试算

`POST /api/salary/rule-trial/normal-grade`

请求字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `personCode` | 是 | 人员编码，格式如 `001-00055` |
| `orgCode` | 是 | 单位编码，格式如 `001` |
| `year` | 是 | 目标历史工资年度 |
| `month` | 是 | 目标历史工资月份 |
| `changeType` | 否 | 变动类型，即历史 `hisbase.jslb`；传入时必须精确匹配同月同类型目标行 |

验收重点：

- 传入 `changeType` 时，只能匹配同月同 `jslb` 的目标历史行。
- 未找到目标历史行时，应返回无目标行或业务错误，不得回退到同月其他类型记录。
- `matchedExpected=true` 时，`calculatedTotalAmount` 与 `expectedTotalAmount` 差额应为 0。
- `changes` 中应包含关键工资项、前后状态、金额差额和 `ruleNote`。
- `expectedDiffs` 应能定位明细差异；已知手工项或数据问题按例外清单处理。

### 批量试算

`POST /api/salary/rule-trial/normal-grade-batch`

`GET /api/salary/rule-trial/normal-grade-batch.csv`

验收重点：

- 批量统计应正确区分匹配、差异、无目标行、跳过、倒档、级别晋升等状态。
- 每条明细应保留 `ruleType/ruleNote`，便于业务筛查。
- CSV 导出应为 UTF-8 BOM，中文表头正常显示。

## 2. 通用验收标准

每类变动至少检查以下内容：

| 检查项 | 通过标准 |
| --- | --- |
| 目标行选择 | 年月、人员、单位、`changeType/jslb` 精确命中 |
| 基线行选择 | 取目标月前最近一条有效历史工资；2006 套改允许无前置基线 |
| 总额对账 | 非已知例外样本差额为 0 |
| 明细对账 | 关键工资项进入 `changes`，金额与目标行一致 |
| 状态展示 | 级别、档次、薪级、岗位、警衔、学历等状态可解释 |
| 津补贴处理 | 标准表项目按岗位和标准年度重算，手工/特殊项目保留或归入例外 |
| 规则说明 | `ruleNote` 能说明适用路径、标准年度、表名或特殊口径 |

## 3. 变动类型验收点

| 变动类型 | 当前处理路径 | 关键验收点 |
| --- | --- | --- |
| `调标晋升`、`调整标准` | 标准年度切换重算 | 岗位/级别/薪级状态不变，按 `tbnd/jbtbz` 切换标准后重算 |
| `津贴变化` | 目标状态及津贴重算 | `jbtbz` 标准项目按 `zwbm2+jbtbz` 取值，手工项不误重算 |
| `职务变化` | 公务员/事业/工人/法检分支 | 职务工资、级别/薪级工资、考核起算年及派生津贴联动 |
| `正常级别`、`正常档次`、`正常晋档`、`级别滚动` | 正常晋档/级别晋升/薪级晋升 | 公务员 5 年晋级、2 年晋档；事业 1 年薪级；工人晋档；教护派生项同步重算 |
| `警衔变化`、`警衔津贴` | 警衔津贴重算 | 按目标警衔和标准年度查津贴，基本工资状态不被误改 |
| `警员套改`、`职级套改`、`职级晋升` | 职级/警员目标状态执行 | 按目标职级编码、级别、档次执行，不反推正常晋升 |
| `转正定级` | 入口定资 | 公务员职务工资优先取转正任职信息；级别档次按学历标准；事业按学历确定薪级 |
| `调入定资`、`转业定资`、`退伍定资` | 入口定资或目标状态重算 | 无正式基线时走入口定资；已有正式基线时按目标状态重算 |
| `见习工资`、`新进工资` | 见习/试用期或正式入口定资 | 见习工资按见习时学历 `dxl.xlbm` 查表；历史行 `xlbm` 不作为唯一依据 |
| `学历变化` | 学历变化重算 | 学历类别为其他/其它不参与工资；同月按 `changeType` 精确选行 |
| `教护津贴` | 教护龄和教师护士提高重算 | `jhlqsny` 从 `dryjbxx` 取值；义务教育 `jxlb=2` 不计算 `JSFSZWTG2` |
| `法检套改` | 法检等级工资套改 | `03` 前缀查 `bz06_zwgz_fj`，结果存 `ZWGZSE2`，不写 `JBGZSE2` |
| `法官等级`、`检察等级`、`监察官等级`、`审判津贴`、`检察津贴`、`监察津贴` | 法检监等级/津贴重算 | 按目标等级和标准年度查对应津贴 |
| `2006套改` | 目标套改行金额重建 + 非金额校验 | 金额项目按目标套改行重建；`TG2006_TGB/XJ/GR` 仅作规则校验和归类 |
| `降资处分`、`奖励晋升`、`其它情况` | 目标状态重算 | 不走正常晋升推导，直接按目标行状态重算 |

`backend/target/probationary-data-issues.tsv`

| F 岗位、无基线、金额 0 | 38 条 | 保留为占位数据，暂不进入回归 |
| F 岗位、有基线、金额 0 | 1 条 | 单独复核历史状态 |

已知例外处理要求：

- 新增例外必须写明样本集、人员、状态和原因。
- 数据补齐后，应从清单移除对应人员并重新运行一键复测。
- 规则差异不得直接加入例外，需先判断是否应补规则或修正数据。

## 8. 验收通过条件

一次业务验收可按以下口径判定：

1. `mvn test` 通过。
2. `verify-salary-samples.ps1 -FailOnUnexpected` 通过。
3. `verify-business-acceptance-samples.ps1 -FailOnUnexpected` 通过，业务抽查样本 `matchedExpected=true` 且总额等于目标金额。
4. 非匹配样本均能归入 `known-sample-issues.tsv` 或明确的数据清理任务。
5. 退休工资、年终一次性奖金不纳入本轮在职试算验收。

# 在职工资业务抽查样本

本文用于前端联调和业务验收时抽查 `POST /api/salary/rule-trial/normal-grade`。

## 调用方式

接口：

`POST http://127.0.0.1:18080/api/salary/rule-trial/normal-grade`

请求示例：

```json
{
  "personCode": "041-00210",
  "orgCode": "041",
  "year": 2024,
  "month": 1,
  "changeType": "学历变化"
}
```

验收时重点看：

- `matchedExpected=true`
- `differenceWithExpected=0`
- `changes` 中关键工资项、前后状态、金额差额、`ruleNote` 是否能解释业务口径

页面入口：

`http://127.0.0.1:18080/`

顶部选择“抽查样本”后点击“载入样本”，页面会自动定位人员、填入年月和变动类型，并执行一次规则试算。

## 复测命令

业务抽查前建议先确认整体回归通过：

```powershell
cd D:\rsgzgl2006nid\backend
powershell -ExecutionPolicy Bypass -File scripts\verify-salary-samples.ps1 -FailOnUnexpected
powershell -ExecutionPolicy Bypass -File scripts\verify-business-acceptance-samples.ps1 -FailOnUnexpected
```

如需查看某类更多样本，可查看：

| 文件 | 场景 |
| --- | --- |
| `target/core-flow-results.tsv` | 津贴变化、职务变化、新进工资 |
| `target/special-flow-results.tsv` | 学历变化、教护津贴、2006 套改、正常档次 |
| `target/rank-judicial-results.tsv` | 警衔、职级、法检等级津贴 |
| `target/target-state-results.tsv` | 降资处分、奖励晋升、其它情况 |
| `target/cross-type-results.tsv` | 综合跨类型样本 |

## 注意事项

- 抽查时建议传入 `changeType`，避免同月多条历史工资记录选错。
- `045-00254`、`107-00350`、`107-00360`、`107-00361`、`002-00104` 属已知例外，不作为业务规则失败样本。
- 退休工资和年终一次性奖金不纳入本轮在职工资试算验收。

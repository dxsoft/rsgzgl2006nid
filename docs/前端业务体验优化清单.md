# 前端业务体验优化清单

当前工作台已经覆盖工资业务核心闭环：待办、已办、试算、快照、历史写入计划、批量写入、撤销、审计、验收。后续优化重点放在经办效率和上线可解释性。

## 1. 上线前必须稳定

- 历史写入和撤销按钮只在对应权限下显示。
- 批量写入、批量撤销必须先显示预览和确认。
- 写入结果必须显示批次号、成功数、失败数、跳过数。
- 写入计划、字段对照、审计流水均可导出。
- 阻断原因必须能在计划详情和批量结果中看到。

## 2. 真实使用后优先优化

- 历史写入计划支持按单位、业务类型、年月、阻断原因快速筛选。
- 批量结果支持只看失败/跳过项。
- 字段对照中突出金额不一致字段。
- 阻断原因按基础信息、任职、学历、考核、链路问题分组。
- 审计导出文件名带批次号。

## 3. 暂缓优化

- 差异原因自动归类；
- 大屏统计；
- 复杂图表；
- 退休工资入口；
- 年终一次性奖金入口。

## 4. 验收方式

每次前端调整后至少验证：

```powershell
node --check backend\src\main\resources\static\app.js
powershell -ExecutionPolicy Bypass -File scripts\verify-launch-readiness.ps1 -SkipPackage
```
